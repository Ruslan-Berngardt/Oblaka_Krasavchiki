# Лабораторная 0: сервис «Кадр»

## Цель

Разработать локально запускаемое приложение из фронтенда, бэкенда и отдельной сетевой базы данных. Реализовать сохранение данных через интерфейс и повторное чтение после обновления страницы.

## Реализация

«Кадр» — сервис для публикации отзывов о фильмах. На главной странице расположен каталог с поиском, жанрами и случайной подборкой. В карточке фильма можно выбрать цитату и написать ревью. После публикации оно появляется на стене автора и в общей ленте.

Фронтенд на HTML, CSS и JavaScript отправляет HTTP-запросы к API и отображает ответы. Бэкенд на Node.js и Express проверяет данные, определяет пользователя по сессии и выполняет запросы к PostgreSQL. База работает отдельным сервисом.

При публикации фронтенд отправляет `POST /api/reviews`. Сервер проверяет оценку, текст и принадлежность цитаты фильму, затем записывает отзыв в таблицу `reviews`. При открытии стены `GET /api/reviews?user=ID` читает сохранённые данные. Поэтому обновление страницы не удаляет публикации.

Docker Compose запускает три сервиса. nginx отдаёт интерфейс и передаёт API-запросы бэкенду; PostgreSQL хранит данные в постоянном томе. Также предусмотрен запуск через `npm start` с отдельно работающим PostgreSQL.

## Показ преподавателю

1. Запущенные сервисы и каталог.

3. Регистрация и публикация отзыва с цитатой.
4. Отзыв после обновления страницы и перезапуска бэкенда.

## Короткая речь для защиты

Мы разработали сервис «Кадр» — небольшой дневник просмотренных фильмов с элементами социальной сети. Пользователь выбирает фильм, ставит оценку, пишет отзыв и при желании добавляет цитату. Отзывы появляются на личной стене и в общей ленте.

Приложение состоит из фронтенда на JavaScript, бэкенда на Node.js и отдельной базы PostgreSQL. Фронтенд обращается к бэкенду по HTTP, а бэкенд читает и записывает данные в БД. После обновления страницы и перезапуска сервера отзыв сохраняется.

Для запуска подготовлены Docker Compose и README. Пользователь может менять только свои отзывы. Автоматические тесты проверяют основные операции с настоящей базой данных.

## Вывод

В ходе работы создан сервис с взаимодействующими фронтендом, бэкендом и отдельной сетевой базой данных. Реализованы чтение и запись отзывов, а также сохранение данных между обновлениями страницы. Приложение подготовлено к дальнейшим лабораторным по nginx, Docker и CI/CD.
