# API сервиса «Кадр»

Базовый путь `/api`, ответы JSON. POST, PUT, DELETE требуют `Content-Type: application/json`; для выхода/удаления достаточно `{}`. Ошибки: `{"error":"Описание"}`. Авторизация — cookie `kadr_session`, которую браузер получает при входе и отправляет автоматически.

| Метод | Путь | Назначение |
|---|---|---|
| GET | /health | Проверка сервера и БД |
| POST | /auth/register | `{name,email,password}`; имя 2–40, пароль 8–128 символов |
| POST | /auth/login | `{email,password}` |
| POST | /auth/logout | Отзыв текущей сессии |
| GET | /auth/me | `{user:{id,name}}` или `{user:null}` |
| GET | /genres | Справочник жанров |
| GET | /movies | Каталог; параметры `search`, `genre` (ID), `random=true` |
| GET | /movies/:id | Фильм, цитаты, последние 30 отзывов |
| GET | /users/:id | Публичные ID, имя и дата регистрации; email скрыт |
| GET | /reviews | Лента; `user` (ID) для стены, `before` для продолжения |
| POST | /reviews | Создание ревью вошедшего пользователя |
| PUT | /reviews/:id | Изменение своего ревью; фильм менять нельзя |
| DELETE | /reviews/:id | Удаление своего ревью |

Пример создания:

```json
{
  "movie_id": 1,
  "text": "История, которую хочется пересмотреть и обсудить.",
  "rating": 9,
  "quote_id": 1,
  "spoiler": false
}
```

Оценка — целое число 1–10, текст — 10–5000 символов после удаления пробелов по краям. `quote_id` необязателен, `null` означает отсутствие цитаты. `spoiler` по умолчанию `false`. Автор определяется по сессии, переданный клиентом `user_id` игнорируется.

Лента возвращает `{reviews:[...],next:number|null}`, по 20 отзывов. Для продолжения передайте `before=next` с прежним `user`, если открыта стена. Средняя оценка фильма — `null`, если отзывов нет.

Коды: 201 — создано; 400 — неверные данные; 401 — нужен вход/неверный пароль; 403 — межсайтовый запрос; 404 — объект не найден или отзыв чужой; 409 — повторный email/отзыв; 415 — неверный Content-Type; 429 — лимит попыток; 500 — ошибка сервера.
